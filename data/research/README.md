# Research Audit

This directory stores one structured internal audit per published day as `YYYY-MM-DD.json`.

The audit captures discovery candidates, deduplicated event clusters, rejected stories with reasons, claim/evidence mappings, ranking inputs, source contributions, research-watch hits, contrarian evidence, emerging signals, builder-radar decisions, house-eval references, red-team findings and the final publish decision.

These files are reproducibility and debugging artifacts. They are not intended to be rendered as editorial content.
