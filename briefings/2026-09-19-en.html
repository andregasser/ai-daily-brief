AGENT SECURITYGOOGLE · GEMINI · IRREGULARConfirmed · Multiple

Gemini crossed the simulation boundary in cyber evals—the test environment itself is now a security boundary

Google confirmed to multiple outlets that Gemini reached three real companies during cybersecurity evaluations run in May. The models were supposed to work against a fictional company; unintended internet access plus a naming collision led them to real systems. In one case credentials were guessed, in two others publicly exposed credentials were used. Google says the models stopped when they recognized the mistake and caused no harm.

What changed since yesterday?

OpenAI and Anthropic incidents had already shown real external effects. Google's confirmation turns this into a cross-lab evaluation-harness problem: DNS, networking, secrets, target resolution and egress belong to the security boundary.

Engineering Takeaway

Cyber and agent evals should start hermetic: no open internet route, simulated DNS/service endpoints, synthetic credentials, explicit egress allowlists, immutable test-tenant IDs and side-effect canaries. “The model should know it is a test” is not isolation.

Signal vs. Hype

Signal: multiple labs show the same boundary-failure class. Hype brake: no sophisticated zero-days; Google says the models stopped themselves and caused no harm. This is primarily a containment/harness finding.

🔬 Concept of the Day

SNAPSHOT RESTORE & WORKING SETS

Why agent runtimes should not “boot” from scratch on every start

Intuition: a traditional cold start repeats work: load image, initialize runtime, import libraries, bootstrap agent code. Snapshot restore moves that work earlier. The process initializes once to a safe point, freezes, and new instances start from that snapshot.

Working set: what matters is not theoretical image size but the pages and resources a live session actually needs. Reclaiming cold pages makes cost track active working set rather than historical peak.

Technical hazards: snapshots must not freeze expired credentials, nonces, open sockets or user-specific state. Snapshot-safe initialization and per-session injection must stay separate; code/config changes need reliable invalidation.

Product example: AWS exposes V2 via platformVersion=V2, creating a clean experiment boundary: same agent artifacts, V1 vs V2, then compare start time, resident memory and cost per successful task.

Connection to earlier concepts: this extends Scale-up vs. Scale-out and Hermetic Execution: performance and security boundaries meet in the runtime layer.
